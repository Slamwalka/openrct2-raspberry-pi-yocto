# Projektbilder

Hier liegen eigene Screenshots, Fotos des Raspberry Pi-Aufbaus und kurze GIFs, die den laufenden Server oder den DSI-Viewer zeigen.

- Nur selbst erstellte oder zur Weitergabe freigegebene Bilder einchecken.
- Keine privaten Schluessel, VPN-Konfigurationen, Passwoerter, SSH-Fenster oder persoenlichen Daten zeigen.
- Bilder auf den relevanten Ausschnitt begrenzen; grosse Aufnahmen vor dem Commit verkleinern.
- Dateinamen kurz und beschreibend waehlen, zum Beispiel `dsi-viewer.jpg` oder `park-tour.gif`.

In der README kann eine Datei so eingebettet werden:

```markdown
![DSI-Viewer auf dem Raspberry Pi](media/dsi-viewer.jpg)
```
